# DRAFT: AI cycle is the proof path; SDLC map is public

Number claimed at merge. Do not mint.

## Status

Proposed (2026-09-10).

## Context

The bench had a working wall (pull → index → named query → envelope draft →
HITL write). The remaining proof looked like a human clicking every finding.
That is not the claim. The director already knows their manual stats. The
owner will not walk the cycle by hand as the demonstration.

A friend named five landscape questions the director will ask:

1. AppSec tools and their AI capabilities, and where this wall sits.
2. The SDLC, and how we make software secure in that life cycle.
3. Vulnerability-management practice.
4. Which AI workflow is a gate at each stage.
5. How this helps product security enterprise-wide.

Scanner vendors now ship Assistant / Guardian / Agentic Workflows (Semgrep),
Remediation Agent and Evo COS (Snyk), Copilot Autofix, and similar. Those
products patch and hunt. They must not own sprint rank or the packet stamp.
This project is the wall around them: scripts count, one compiled index,
orchestrator collisions, model drafts, human apply and sign.

Customer tenants, SOWs, logos, Jira, and hours-as-sell-unit stay out
(C-PUBLIC). Public Juice Shop pins remain the corpus.

## Decision

1. **The POC is the AI cycle.** One user click drafts four tasks (triage,
   ticket, close, packet) from named envelopes on `K-JWT`. `draftCycle` is
   sequential, user-initiated, `max_tokens` 500, envelope ≤ 8000. Empty
   envelopes refuse. Apply is one human write. Sign is one human stamp.
2. **Accept ships the cluster and unblocks sign.** It decides the v17
   worklist (ship `K-JWT`, already for existing tickets, drop noise and
   out-of-scope), upserts `JUICE-POC-JWT`, writes close evidence on
   `JUICE-7` and `JUICE-9` only, and sets the packet draft. It does not
   sign. X-GONE-OPEN therefore clears from evidence, not from a model close.
3. **Director contrast fields stay empty.** Cycle time, findings copied,
   packet hours are typed at demo. This bench never invents a tenant number.
   Scripted Juice Shop counts are the only numbers it claims.
4. **The SDLC tab renders `landscape.ts`.** Tool-AI, NIST SSDF gates, VM
   practices, and product-security rows are public. They are not a customer
   tenant. Scanner-AI is Layer 1. This wall is the release and VM gate.
5. **Sign's orchestrator href is `/poc`.** The human who picks the ready
   sign node lands on the director path.

C-HITL, C-SCRIPT, C-REFUSE, C-ORCH, C-POINT, C-PUBLIC stay. The model still
does not count, rank, sequence, or write.

## Alternatives considered

- **Click every finding as the trial.** Rejected. That is the director's
  known manual path, not this proof.
- **Let scanner-AI rank the worklist.** Rejected. DROP_RULES and scripts
  rank. Vendor AI may patch in the IDE. It does not own the sprint.
- **Attach a customer tenant to fill contrast fields.** Rejected. C-PUBLIC.
- **Auto-sign after apply.** Rejected. K-WRITE. The stamp is the demo.

## Consequences

- PROTOCOL rev `2026-09-10`. Goal, Trial, BUILD, SDLC, and INTENT.not match
  `protocol.ts`.
- Manual stats remain a demo input. A filled-in number in git would be a
  C-PUBLIC miss.
- Accept is a bulk HITL write scoped to the POC cluster plus gone-open
  evidence. It is not a general auto-triage of every future pin.
- Landscape rows will drift as vendors rename products. Update
  `landscape.ts`, not PROTOCOL prose.
